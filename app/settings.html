HOW TO GET A KEY
  1. 到 clawrouter.com 註冊帳號
  2. 儲值（建議先 USD 20 試水溫）
  3. 建立一支 API Key（會是 sk-claw-... 開頭）
  4. 複製整串貼進上方 API Key 欄位 → 按「儲存 Key」
  5. 按「Test Connection」確認可以用
