本地語音 AI 助理

計畫書 · 建立 2026-06-08 · 對象：KC · 目標：Jarvis 級語音控制 Claude Code & Cowork

一句話目標：做一個常駐桌面右下角的液態玻璃浮動視窗，喊「Hey Claude」就能用講的指揮 Claude Code 寫程式、叫 Cowork 處理工作、查任務進度、純粹聊天，Claude 用聲音念回給你聽。

一、產品願景

整體體驗對標 Jarvis（鋼鐵人 AI 管家）：常駐、低存在感、隨叫隨到、語音雙向、視覺上像未來感的全息浮窗。

四大使用情境

情境典型指令範例
請 Claude 寫程式 / 改檔案「Hey Claude，幫我把 LendOS 那個 contract 的 bug 修一下」
請 Claude 處理日常工作 MVP 優先「Hey Claude，幫我寫一則推文宣布 PerpOS 上線」
查看任務狀態「Hey Claude，現在那個推文寫到哪了？」
純粹聊天 / 問問題「Hey Claude，GMX 的多資產 LP 是怎麼設計的？」

架構決策歷程：

  1. 原案：透過 Cowork 內建 MCP 把語音指令注入既有 session — 因 send_message 工具要求人工確認且明示不適合編排，不可行。
  2. 第二案：用 Claude Agent SDK 自跑 Claude + Anthropic 直連 API — 技術可行但 KC 希望保留多模型彈性。
  3. 最終案（2026-06-08）：改用 Claw Router（OpenAI 相容多模型閘道），openai npm 套件指向 https://clawrouter.com/v1，手寫 agent loop。失去Claude Agent SDK 的 MCP 自動整合，換得單一帳號管 Claude / GPT / Gemini / DeepSeek 等 112+ 模型 + 任務級的模型自動路由。

三、系統架構（白話版）

零件功能選用技術為什麼選它
桌面浮動視窗 UI 本體、玻璃效果、常駐最上層 Electron + Windows 11 Acrylic 網頁技術做桌面 App、原生玻璃材質支援

工具能力 讓 AI 能讀寫檔案、跑指令、查網頁 自寫的 OpenAI function-calling 工具：檔案系統 / Bash / WebFetch MVP 不掛 MCP，未來如需 Cowork skills 可另寫 MCP-to-OpenAI 橋接
API 金鑰管理 儲存 Claw Router API Key（sk-claw-*） Electron safeStorage 加密儲存 跟 Windows 登入帳號綁定，不會以明碼存在硬碟；不在聊天介面輸入

預估費用

語音輸入輸出層免費，唯一付費項目是 Anthropic API（Claude 本身的算力）：

  • STT（本地 Whisper）：USD 0
  • TTS（Edge TTS）：USD 0
  • 喚醒詞（Porcupine）：USD 0
  • Claw Router API：依用量付費
    • 輕量混搭策略：閒聊用 GPT-4o-mini / Haiku、寫稿用 Sonnet、長文用 Opus 4.6
    • 假設每天 30 分鐘語音對話，約 50 萬 tokens
    • 純 Sonnet 約 每月 USD 100~150（NTD 3,000~4,500）（Router 通常有小幅加價）
    • 智慧混搭路由可降到 每月 USD 40~70（NTD 1,200~2,100）
    • 實際單價請見 clawrouter.com 後台
  • 提供 UI 內建用量儀表板，每天即時顯示燒了多少錢，可設月額上限自動斷線

四、開發路線圖

第一階段 — MVP「能用就好」

預估：3~5 個全工作天 · 目標：語音閉環、能做事

  • Electron 桌面浮動視窗（液態玻璃風格初版）
  • 先不做喚醒詞，改用按熱鍵說話（按住 Ctrl+Space 錄音）
  • 語音轉文字（本地 Whisper）
  • 把文字丟給 Claude Agent SDK 處理，給它檔案系統 + Bash 工具
  • Claude 回覆顯示在視窗 + Edge TTS 念出來
  • API Key 加密儲存 + 基本用量計數器

第二階段 — 完整版

預估：再 1~2 週 · 目標：Jarvis 體驗到位

  • 「Hey Claude」喚醒詞（Picovoice Porcupine）
  • 掛載你 Cowork 在用的 skill 與 MCP（baoyu-skills、marketing-god、notion 等）
  • Haiku / Sonnet 自動路由（簡單問題用便宜模型）
  • 視窗即時顯示任務狀態（Claude 正在做什麼）
  • 講「停」可以中斷正在進行的任務
  • 液態玻璃 UI 細節打磨（動畫、聲波視覺化、狀態色）

第三階段 — 進階體驗

預估：再 1~2 週 · 目標：日常生產力工具

  • 對話記憶（多輪對話接續上下文，含 prompt caching 省錢）
  • 多任務並行（同時跑多個背景任務）
  • 鍵盤快捷鍵、系統列圖示、開機自動啟動
  • 對話歷史紀錄、可搜尋
  • 聲音偏好設定（選不同 TTS 音色）
  • 用量儀表板：每日 / 每月花費、月額上限自動斷線

五、風險與不確定

1. Claw Router 費用會失控

用量按 token 計費，講話沒節制可能一個月燒到 USD 200+。
對策：UI 內建即時用量儀表板（每天、每月）；可設月額上限，超過自動暫停；模型自動路由把便宜任務丟給 Haiku / GPT-4o-mini；長對話自動截斷舊上下文。

1b. Claw Router 作為中介的風險

所有 prompt 與回覆都經過 Claw Router 伺服器。萬一服務中斷，整個語音助理就斷線；另需信任 Router 不留存敏感對話。
對策：架構模組化，baseURL 可一鍵切回 Anthropic 直連或其他相容 router（如 OpenRouter）；敏感任務（金融、密碼）由 UI 提示「此類請改用本機處理」。

2. 喚醒詞會持續吃資源

Porcupine 大概吃 1-2% CPU，筆電待機久了會多耗一點電。
對策：提供「關閉喚醒詞」開關，改用快捷鍵啟動。

3. 繁中口語化、中英混雜

講「幫我改 LendOS 的 contract」這種中英混雜，本地 Whisper（medium 模型）大致 OK 但偶爾會把英文 token 辨識錯。
對策：給 Whisper 加 prompt 提示常用詞彙；視窗上顯示辨識結果讓你能口頭修正；若不滿意可一鍵切換到付費 OpenAI Whisper API。

4. Edge TTS 非官方 API 風險

Edge TTS 是利用 Microsoft Edge 瀏覽器的內部 API，技術上不算官方公開介面。社群已穩定使用 3 年以上，但理論上 Microsoft 可能調整或關閉。
對策：架構模組化，TTS 可隨時切換。備案為 Windows 內建語音（Hanhan / Yating，完全離線，機械感稍重）；極端情況再升級到 OpenAI TTS。

5. 本地 Whisper 吃資源

每次聽寫時 CPU 會衝到 30~50% 維持幾秒鐘，筆電風扇可能會轉一下。
對策：第一階段先用 medium 模型平衡準度與速度；若想更輕量可降到 small 模型；有 GPU 的話可改用 GPU 加速版本。

6. 這是真的開發專案

不是裝個套件就完成的等級，MVP 也需要幾天。
對策：一步一步來，每個小段落都跑得起來再進下一步，不會丟一堆程式碼讓你看不懂。
